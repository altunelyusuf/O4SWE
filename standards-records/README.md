# Standards records (files held privately)

This folder records standards whose files the Owner supplied on 2026-10-13 for knowledge-base work. **The files themselves are not in this repository.** They are copyrighted by ISO, IEC and IEEE ("all rights reserved"; no part may be posted on the internet without written permission), the copies supplied are institutional licensed copies whose licence is restricted to the licensee, and this repository is public. Publishing the files, or text extracted from them, here would be redistribution.

`STANDARDS_RECORDS.tsv` lists each file with identifier, title, edition, page count, SHA-256 and size, so that a copy handed to a processing session can be recognised as the same file.

## How to process them

Work from the Owner's copies, outside any public repository. Record in the public ontology only what the rights allow: identifiers, titles, edition, clause numbers and counts, and the result of checks. Reproducing clause titles or text, or placing them in a public repository, needs the rights holders' permission or the Owner's confirmation that the licence allows it.
